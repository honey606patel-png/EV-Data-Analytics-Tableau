# ⚡ Global Electric Vehicle Market Performance & Data Analytics

An end-to-end Data Analytics & Business Intelligence solution evaluating global Electric Vehicle (EV) industry trends, battery technology adoption, manufacturer market share, and customer satisfaction across 3 strategic industry scenarios.

---

## 🚀 Tech Stack & Tools
* **Database:** SQLite (Relational DDL & Analytical Aggregations)
* **Data Visualization:** Tableau Desktop / Tableau Public (Calculated Fields, LOD Expressions, Interactive Dashboard, 4-Scene Story)
* **Web Frontend Integration:** Python Flask, HTML5, Bootstrap 5, Tableau Embedding API v3
